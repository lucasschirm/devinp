### Phase 1 — Zero-quota recon (≈2 h, local)

1.1 **Host install layout** — record (largely done): wrapper script content,
`XDG_DATA_HOME` override, `_versions` tree, real-binary path + size +
`file(1)` type, devin version. Note the operational consequence for the
adapter: mount the **real binary + `_versions` tree**, never the wrapper
(PLAN §3.1), and never mount host XDG dirs.

1.2 **Binary forensics (no quota, no container needed):**
- `ldd`/`objdump -T | grep GLIBC_` on the real ELF → max required GLIBC
  version (the offline glibc requirement record).
- CA behavior: `strings` for CA bundle paths (`/etc/ssl/certs`,
  `certifi`, etc.) → record whether devin uses system CAs or a bundled set.
- These two are the fallback record if Phase 3 can't run; otherwise Phase 3
  supersedes them.

1.3 **Pin SWE-bench harness + Verified split (AC4, no images needed yet):**
- In the `bench/` venv: install a **pinned** `swebench` version (record
  exact pin + why: the one the leaderboard/README for Verified uses).
- Read the pinned source (`swebench/harness/run_evaluation.py` +
  `model_patch` handling) and **confirm** the predictions-file format:
  `instance_id`, `model_name_or_path`, `model_patch` — quote the relevant
  loader code into the notes.
- Pull the Verified split metadata (HF `swebench-verified` / local `swebench`
  dataset module) → 500 instance IDs, per-instance `sweb.eval.x86_64.<id>`
  image names, base-image versions. Identify the **oldest** base image
  (lowest OS/glibc) — that's the compat test target for 3.1. Save the full
  instance→image→base table in the notes (WP1 needs it for pruning §7).

### Phase 2 — ACP surface + models + auth (1–2 real sessions)

2.1 **Write `bench/probes/acp_probe.py`** (no devin needed to write it):
- Spawns `devin acp --model <M>` with isolated ephemeral XDG dirs + isolated
  `--config` (empty MCP/rules/plugins; `DEVIN_REFUSAL_FALLBACK` unset — the
  exact hygiene PLAN §3 demands, even for a recon probe).
- **Framing evidence:** send JSON-RPC 2.0 as bare NDJSON lines over stdio
  (no `Content-Length:` headers) and record that the server replies per line;
  also record what happens if an LSP-style header is sent (expect
  non-response/hang) — positive + negative evidence that framing is NDJSON.
- **Passive mode:** log first ~30 s of unsolicited frames without sending
  anything → captures startup vendor notifications (expect
  `_cognition.ai/mcp/serversChanged`); record every distinct method name seen.
- **Handshake mode:** `initialize` → `session/new` (cwd) → `session/prompt`
  (trivial task) → auto-allow `session/request_permission` (record its request
  shape: tool name, kind, options) → record prompt-completion
  **stop-reason + usage metadata fields** → `session/close` → clean exit.
  Dump raw (sanitized) frames to `bench/notes/raw-frames.jsonl`.
- **Never** treats unsolicited notifications as errors; logs them.

2.2 **Run the probe** (delegated per Phase 0.3, `--model swe-2-high`):
- Session 1 = the hand-driven AC6 session: trivial task in a sandbox
  container (Phase 0 runtime), full lifecycle with `session/close`, wall-clock
  timed. If the container path is blocked (Phase 0 fallback c), run on the
  delegated workspace host and mark the container portion accordingly.
- `devin models list --format json` → save raw to `bench/notes/models-list.json`;
  record the shape (fields, `cost_tier` values) and confirm the free set
  (`swe-2-medium/high/max`) vs paid (`swe-1-6/1-7`, `*-lightning`).
- `devin auth status` → record plan/quota fields verbatim.
- **AC1 + AC5 + (part of AC3/AC6) done** once the probe output + models JSON +
  auth status are recorded in the notes.

### Phase 3 — In-container verification (needs runtime from Phase 0)

## Risks & contingencies

| Risk | Contingency |
|---|---|
| No container runtime obtainable (Phase 0) | Fallback chain 0.2a→b→c; offline glibc/CA record (1.2) + explicit open-risk note + WP1 pilot gate. Never claim in-image verification that wasn't run. |
| Devin bash-block in this session | All live devin via `devin_delegate`; delegated session = the budgeted probe session (quota ledger in PR body) |
| ACP surface differs from PLAN.md expectations | Record observed truth (that's the point of recon); flag diff to #9 so WP1 `acp_client.py` is built on WP0 evidence, not assumptions |
| Free-tier quota smaller/reset window different than assumed | Budget is config not code (PLAN §2.2); conservative default, fail-closed `cost_tier` gate is WP1's, WP0 just records the numbers |
| Probe burns more than 1 session (retries, flaky close) | Hard cap: 2 sessions max for all of Phase 2+3; on the 3rd attempt abort and record partial evidence + gap |
